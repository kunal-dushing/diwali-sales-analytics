# Diwali Sales Analytics Dashboard

An interactive dashboard for exploring synthetic Amazon-style Diwali sales data. This is a learning project and is not affiliated with Amazon.

## Dashboard features

- Filter results by festival phase, category, city, and sales channel.
- View revenue, profit, units sold, and profit margin.
- Compare revenue and profit by festival phase.
- Explore average discounts by category and revenue by product.
- Responsive layout with a festive light theme.

## Files

- `index.html` — dashboard page and chart code.
- `diwali_orders.csv` — synthetic practice orders used by the dashboard.

Keep both files in the same folder when hosting the site.

## Deploy with Vercel

This repository is connected to Vercel. Commit changes to the `main` branch on GitHub to start a new deployment. Vercel serves the static site from the repository root, where `index.html` is the home page.

## Data note

The dataset is synthetic practice data. It does not contain live Amazon offers, prices, or sales figures.
